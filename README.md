# Job Board Applications Analysis

## What I Did
- Started with 1200 applications
- Removed 6 duplicate rows
- Removed 15 rows with blank source
- Final dataset: 1179 clean rows

## Key Findings
- Best Source: Referral - 10.7 hires per 100 applications
- If 4 steps are completed: 48% shortlist rate, otherwise only 9%
- Paid applications: Reply in 3 days
- Unpaid applications: Reply in 7 days, 30% never get a reply

## How to Run
python analysis.py

## Files
- analysis.py - Data cleaning and analysis code
- cleaned_data.csv - Final cleaned dataset
